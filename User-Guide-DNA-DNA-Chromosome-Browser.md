# DNA chromosome browser

![DNA chromosome browser](images/user-guide/dna-chromosome-browser.png)

Visualize shared genetic segments across chromosomes 1 through 22 and the X chromosome to perform segment triangulation and crossover mapping. Open this screen when you want to analyze DNA match segment data imported from supported exports.

## What you see

The upper section contains the reference kit selection control and the view selector tabs for **Clusters** and **Chromosome Browser**. The canvas displays shared segments painted across chromosome ideograms. The lower panel shows detail fields for a selected segment, including parental side options, label and color controls, and ancestor linking.

## Common tasks

### View segment details

1. Click a painted segment on the canvas.

The lower panel displays the match name, centimorgans, position range, and editing fields for the selected segment.

### Assign parental side to a segment

1. Click a segment on the canvas to open its details in the lower panel.
2. Select **Maternal**, **Paternal**, or **Unplaced** under **Side**.
3. Select **Save segment**.

### Link an ancestor to a segment

1. Click a segment on the canvas.
2. Select **Link ancestor**.
3. Choose an individual from the picker.
4. Select **Save segment**.

## Good to know

- AncestryDNA does not provide segment data, so you must import an FTDNA or GEDmatch export to use this screen.
