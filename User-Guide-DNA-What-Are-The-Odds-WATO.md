# What Are The Odds (WATO)

![What Are The Odds (WATO)](images/user-guide/wato.png)

The What Are The Odds (WATO) tool tests multiple genealogical placement hypotheses for an unknown person or mystery match against known DNA match amounts. Open this view when you want to evaluate how well different common ancestor scenarios fit your DNA test data.

## What you see

The upper section provides a **Scenario label** input field for naming your current testing hypothesis set. Below that, the **Testers** section contains a person picker control labeled **Add a tester** to include known DNA matches and a list showing added testers with remove options. The **Hypotheses** section lists individual hypothesis blocks containing **Label**, **Common ancestor family id**, and **Generations below** input fields alongside an **Add hypothesis** button. At the bottom, a **Save and compute** button triggers the scoring calculation. When computation completes, the screen displays results in a table with columns for hypothesis names, combined likelihood scores, odds versus the second best option, and support reads.

## Common tasks

### Run a DNA scenario calculation

1. Enter a name in the **Scenario label** field.
2. Select **Add a tester** to choose a known DNA match.
3. Select **Add hypothesis** to create a placement hypothesis.
4. Enter values in the **Label**, **Common ancestor family id**, and **Generations below** fields.
5. Select **Save and compute** to generate the likelihood results table.
