# Extraction proposals list

![Extraction proposals list](images/user-guide/extraction-proposals.png)

Review individual structured claims generated from evidence documents before you merge them into your family tree. Open this screen when you process document extractions and need to inspect factual candidates extracted by the program.

## What you see

The grid area contains the main table listing all proposals, showing columns for kind, proposal details, reference keys, confidence scores, review reasons, status, and actions.

The proposal rows display individual data points such as people, relationships, facts, places, and source citations extracted from your documents.

The action column contains individual **Reject** buttons for pending proposals.

## Common tasks

### Reject a proposal

1. Locate the proposal row with a status of pending in the table.
2. Select **Reject** in that row. The status updates to show the rejection.

## Good to know

Pending proposals display a **Reject** button, while processed proposals show their current status in the status column.
