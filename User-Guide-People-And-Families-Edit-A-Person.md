# Edit a person

![Edit a person](images/user-guide/person.png)

The Person editor displays biographical details, life events, relationships, parentage, citations, and attached evidence personas for a selected individual. You open this screen when you want to update names, review timelines, or check family connections for someone in your tree.

## What you see

The top command bar holds controls to return to the index, save modifications, or open a separate dialog using **Back to People**, **Save Changes**, and **Popup Dialog**.

The identity section provides text boxes and selectors for **Prefix (Title)**, **Suffix**, **Given Names**, **Surname**, and **Sex / Gender**, alongside a privacy switch.

The relationships and events areas display family links and the life timeline for the individual.

The side panel lists **Evidence & Persona Citations** and direct source links tracked for the individual.

## Common tasks

### Edit a person name or details

1. Select the **Given Names** or **Surname** input field and type the correct text.
2. Select **Save Changes** to record the updates and display a confirmation badge.

### Toggle record privacy

1. Select the **Privacy Record** switch to change the status between public and private.
2. Select **Save Changes** to store the setting and display a confirmation badge.

### Open the record in a separate window

1. Select **Popup Dialog** in the command bar to open the editor in a dedicated modal.
