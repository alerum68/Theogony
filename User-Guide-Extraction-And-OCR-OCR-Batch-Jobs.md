# OCR batch jobs

![OCR batch jobs](images/user-guide/ocr-jobs.png)

Track batch text recognition jobs across multiple media files to monitor queue status, progress, duration, and error reporting. Open this screen when you want to check the progress of document extractions sent to the Gemini 24-hour Batch API.

## What you see

The top toolbar contains the **Refresh from Gemini** button, which updates the job list from the server. Below the toolbar, the main area displays a table when jobs are present, showing columns for job identification, model, status, submission time, progress, and cost. When no jobs exist, an empty state message appears with instructions to submit multiple documents from the Staging screen.

## Common tasks

### Refresh batch job status

1. Select **Refresh from Gemini** in the top right corner of the screen.
2. View the updated table to check current progress and status changes for active jobs.

### Cancel a running job

1. Locate the active job in the table.
2. Select **Cancel** in the actions column for that job.
