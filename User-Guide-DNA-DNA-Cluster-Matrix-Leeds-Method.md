# DNA cluster matrix (Leeds method)

![DNA cluster matrix (Leeds method)](images/user-guide/dna-cluster-matrix.png)

Organize genetic DNA matches into distinct maternal and paternal branches using the automated Leeds Method. Open this screen when you want to group your shared matches by common ancestors and label each cluster.

## What you see

The top toolbar contains the **Reference kit** dropdown to select whose matches you want to cluster, along with **Min shared cM** and **Max shared cM** input fields to filter match sizes. 

The main canvas displays the cluster matrix grid, plotting matches against each other based on shared DNA segments.

The side panel lists each detected cluster with its member count, a text area for naming the cluster, and action buttons to save the label or link an individual from your tree.

## Common tasks

### Change the reference kit

1. Select the **Reference kit** dropdown.
2. Choose a different kit from the list to recalculate the matrix.

### Adjust match thresholds

1. Enter a new value in the **Min shared cM** input field to change the lower centimorgan limit.
2. Enter a new value in the **Max shared cM** input field to change the upper centimorgan limit.

### Label a cluster

1. Type a name in the text area under the cluster heading in the side panel.
2. Select **Save label** to store the text.

### Link an ancestor to a cluster

1. Select **Link ancestor** in the target cluster card.
2. Choose the correct person from the search list to connect them to the cluster.

## Good to know

- The program automatically recalculates clusters whenever you change the reference kit or centimorgan boundaries.
- Colors in the matrix cycle through a fixed palette based on the order of seed matches.
