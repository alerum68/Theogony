# Media staging and gallery

![Media staging and gallery](images/user-guide/staging.png)

Import document scans, photographs, and certificates here to prepare them for optical character recognition and information extraction. Open this screen when you want to add new media files to your research before turning them into permanent source documents.

## What you see

The upper toolbar shows the screen title, the staged file count, and **Refresh**.

The drop zone provides an area to drag files or select **Browse files** to open them from your computer.

The content area displays your staged files and groups in a structured list, showing checkboxes, filenames, mime types, sizes, and individual action buttons.

## Common tasks

### Stage new files

1. Drag document scans or photographs into the drop zone, or select **Browse files** to choose files from your computer.
2. View the newly added files in the content area list.

### Inspect text or run extraction

1. Select **Text / OCR** next to any staged file to open the inspection dialog.
2. Choose between the **Text (OCR)** tab and the **Extraction** tab to review the data.
3. Select **Close** when finished.

### Promote a file to a source document

1. Select the checkbox next to one or more staged files.
2. Select **Promote Selected** to open the promotion dialog.
3. Enter a title, choose a repository, and select **Promote to Source Document**.

## Good to know

- Select multiple files using their checkboxes to perform bulk actions such as OCR processing or group promotion.
- Group related pages together using **Group Selected** so you can manage multi-page documents as a single unit.
