# Proposal review cards

![Proposal review cards](images/user-guide/review-cards.png)

The Review Cards interface lets you accept, modify, or reject AI-proposed facts, linking evidence personas to conclusion individuals in the database. Open this screen from the review queue when you have data waiting for processing.

## What you see

The top action bar displays the **Accept all resolved** button alongside a count of ready items and any error messages.

The main work area contains review cards for each person proposal, showing labels, confidence percentages, and review reasons.

Each review card provides target selection controls to link existing individuals or create new ones, alongside member rows with checkboxes and field editors for facts, dates, and places.

## Common tasks

### Accept all resolved proposals

1. Review the proposed facts and answer any highlighted fields on the cards.
2. Select **Accept all resolved** at the top of the screen to process all valid items at once.

### Review an individual card

1. Locate the specific person proposal card you want to process.
2. Select **Link to existing** or **Create new** under the target picker.
3. Select **Accept** at the bottom of that card to apply those changes.

## Good to know

- Saving happens automatically when you accept proposals.
- You can undo accepted changes from Edit History.
